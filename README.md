# Custom Employee Portal with Zoho One Integration

A full-stack employee portal built using React.js, Node.js, Express.js, PostgreSQL, JWT Authentication, and Zoho One API integration.

## 🚀 Features

- Secure employee authentication
- JWT-based authentication
- Role-Based Access Control (RBAC)
- Employee dashboard
- Admin dashboard
- User and role management
- Permission-based access
- Zoho One integration
- Secure backend API
- PostgreSQL database
- Input validation
- Error handling
- Protected routes
- Environment variable configuration
- Responsive React frontend

## 🛠️ Technologies Used

### Frontend
- React.js
- Vite
- JavaScript
- HTML5
- CSS3

### Backend
- Node.js
- Express.js
- JWT
- bcrypt
- REST APIs

### Database
- PostgreSQL
- In-memory PostgreSQL fallback for development

### Integration
- Zoho One APIs
- Zoho OAuth 2.0
